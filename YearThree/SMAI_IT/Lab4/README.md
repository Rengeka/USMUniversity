# Лабораторная Работа 4

## Цель работы
Ознакомление студентов с расширенными возможностями платформы Zabbix: создание
графиков и отчётов, использование сложных элементов (item), корреляция метрик и
оптимизация системы мониторинга.

## Задачи
1. Использовать зависимые (dependent) и вычисляемые (calculated) элементы данных.
2. Настраивать шаблоны (templates) для групп хостов.
3. Создавать пользовательские графики и автоматические отчёты.
4. Интерпретировать и сопоставлять собранные данные (например, CPU + память + сеть).
5. Настраивать условные оповещения по нескольким критериям.
6. Оптимизировать параметры сбора данных и уведомлений.

## Вопросы

1. Dependent item берёт данные из master item и может их обрабатывать, а Calculated item вычисляет новые значения на основе формулы из других item’ов.

2. Несколько метрик можно отображать на одном графике, добавляя их как линии с разными цветами и, при необходимости, разными осями Y.

3. Шаблоны позволяют автоматически применять настройки item’ов, триггеров и графиков ко многим хостам, снижая ошибки и упрощая поддержку.

4. Меньший update interval даёт более точные данные, но увеличивает нагрузку на сервер и агент, а больший снижает нагрузку, но обновления происходят реже.
