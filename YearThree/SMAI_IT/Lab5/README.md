## Вопросы

1. Плагин Zabbix в Grafana необходим для подключения и визуализации данных мониторинга из Zabbix в виде продвинутых дашбордов Grafana.

2. Zabbix API играет ключевую роль как промежуточный слой, через который Grafana получает доступ к метрикам и данным мониторинга из Zabbix.

3. Graph panel отображает данные в виде временных рядов и графиков, тогда как Stat panel показывает текущие значения метрик в виде отдельных чисел или состояний.

4. Переменная dashboard — это динамический параметр, который позволяет фильтровать и изменять отображаемые данные across multiple panels без изменения самих запросов.

5. Alert на основе данных Zabbix настраивается через создание правил оповещений в Grafana, которые используют метрики из Zabbix Data Source и задают условия для триггеров уведомлений.
