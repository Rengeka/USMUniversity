# Lab 5

## Цель работы 
Ознакомиться с сервисами Amazon RDS (Relational Database Service) и Amazon DynamoDB, а также научиться:

1. Создавать и настраивать экземпляры реляционных баз данных в облаке AWS с использованием Amazon RDS.
2. Понимать концепцию Read Replicas и применять их для повышения производительности и отказоустойчивости баз данных.
3. Подключаться к базе данных Amazon RDS с виртуальной машины EC2 и выполнять базовые операции с данными (создание, чтение, обновление, удаление записей - CRUD).
4. (Дополнительно) Ознакомиться с сервисом Amazon DynamoDB и освоить работу с хранением данных в NoSQL-формате.
